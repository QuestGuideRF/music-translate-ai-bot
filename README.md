## 📋 Описание

Этот бот использует передовые технологии искусственного интеллекта для распознавания текста песен из аудиофайлов и их автоматического перевода на русский язык. Просто отправьте аудиофайл боту, и он вернет вам текстовую расшифровку с переводом!

### ✨ Возможности

- 🎤 **Распознавание речи** - использует модель Whisper от OpenAI для точной транскрибации
- 🌍 **Многоязычный перевод** - автоматический перевод с любого языка на русский
- 📱 **Telegram интеграция** - удобный интерфейс через Telegram
- ⚡ **Быстрая обработка** - оптимизированная обработка аудиофайлов
- 📄 **Текстовый файл** - результат возвращается в виде удобного текстового файла

---

## 🛠 Технологии

### Используемые модели:

- **Whisper** от OpenAI - высокоточная модель распознавания речи
- **Helsinki-NLP** от Группы исследований языковых технологий Хельсинкского университета - модель машинного перевода

### Библиотеки:

- `python-telegram-bot` - работа с Telegram Bot API
- `openai-whisper` - распознавание речи
- `transformers` - работа с моделями машинного обучения
- `torch` - фреймворк глубокого обучения
- `pydub` - обработка аудиофайлов
- `accelerate`, `sentencepiece`, `sacremoses` - вспомогательные библиотеки для NLP

## 📦 Установка

### Предварительные требования

- Python 3.7+
- FFmpeg (для обработки аудио)
- pip (менеджер пакетов Python)

### Пошаговая установка

#### 1️⃣ Установка системных зависимостей

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install ffmpeg python3-pip
```

**macOS:**
```bash
brew install ffmpeg
```

**Windows:**
- Скачайте FFmpeg с [официального сайта](https://ffmpeg.org/download.html)
- Добавьте в переменную окружения `PATH`

#### 2️⃣ Установка Python-зависимостей

```bash
pip install transformers torch accelerate sentencepiece sacremoses python-telegram-bot openai-whisper pydub
```

Или установите все зависимости одной командой:
```bash
pip install transformers torch accelerate sentencepiece sacremoses python-telegram-bot openai-whisper pydub
```

#### 3️⃣ Настройка бота

1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
2. Получите токен бота
3. Откройте файл `config.py` и добавьте токен:
```python
tg_key = "ВАШ_ТОКЕН_БОТА"
```

## 🚀 Использование

### Запуск бота

```bash
python3 tg_bot.py
```

### Работа с ботом

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start` для начала работы
3. Отправьте аудиофайл боту (форматы: MP3, WAV, M4A и др.)
4. Дождитесь обработки (обычно несколько секунд)
5. Получите текстовый файл с расшифровкой и переводом!

### Команды бота

- `/start` - начать работу с ботом
- `/help` - получить справку

### Ограничения

- Максимальная длительность аудиофайла: **10 минут**
- Поддерживаются основные аудиоформаты (MP3, WAV, M4A, OGG и др.)

## 🔧 Архитектура

1. **Получение файла** - бот получает аудиофайл от пользователя
2. **Проверка длительности** - проверка, что файл не превышает 10 минут
3. **Сохранение файла** - временное сохранение на сервере
4. **Транскрибация** - распознавание речи с помощью Whisper
5. **Перевод** - автоматический перевод текста на русский язык
6. **Сохранение результата** - создание текстового файла
7. **Отправка пользователю** - отправка результата в Telegram

## 🐛 Решение проблем

### Ошибка: "Длительность файла не должна превышать десять минут"
- **Решение:** Обрежьте аудиофайл до 10 минут или меньше

### Ошибка: "Возникла ошибка обработки файла"
- **Решение:** Убедитесь, что файл имеет правильный аудиоформат (MP3, WAV, M4A)

### Бот не отвечает
- **Решение:** Проверьте, что бот запущен и токен в `config.py` правильный
